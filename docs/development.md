# 開発と確認の方法

**未入力の記録欄です。ここに書かれた項目だけで、アプリや実行コマンドが用意されているわけではありません。** `main`にはアプリ本体がありません。企画に必要な最小構成をチームで決め、Copilotに作ってもらった実際の設定に合わせて更新します。確認結果は[verification.md](verification.md)へ残します。

- 実行環境・バージョン：未決定

CodespacesにはNode.js 24を用意しています。これは開発環境の初期値で、ReactやNode.jsのアプリを必須にするものではありません。別の環境を採用したら `.devcontainer/` も合わせます。

| 操作 | 実際の手順・コマンド | 必要なタイミング |

| 依存関係の準備 | 未作成 | 初回・依存関係の更新時など |

Copilot appのボタンを使う場合は、コマンドが動くことを確かめてから `.github/github-app.yml` に登録し、Appで内容を確認して受け入れます。Codespacesでのみ実行する場合は、PC用のSetup／Runを用意する必要はありません。

初回の実装で採用構成に合う最小限の確認を作り、同じ確認をPRでも実行できるようにします。CIが存在しない、実行されない、skipされた場合は成功ではありません。学生による手動確認も別に行います。
