# Planへ渡す企画資料

前段のワークで作った課題シート、アイデアのメモ、共有したい資料を**このフォルダの直下**へ置きます。ファイル名や形式を統一する必要はありません。

- PDF、Markdown、テキスト、画像など、チームで用意したものを使います。
- UIのイメージ画像やFigmaは任意です。文章の企画だけでも始められます。
- 例：`docs/企画シート.pdf`、`docs/アイデア.md`。これは置き方の例で、両方を用意する必要はありません。
- チームのForkはPublicです。公開してよい内容だけ置きます。

CodespacesではExplorerの`docs`へUpload、Copilot appではcloneしたプロジェクトの`docs`へコピーします。GitHubで追加する場合は作業ブランチの **Add file → Upload files** を使い、既存の開発環境に同じブランチをPullします。

置いた後は[READMEのPlan](../README.md#plan)へ進み、**今回使う実際のファイル名**を列挙して参照・添付します。この案内ファイルは入力資料に含めません。

PDF・画像などを読み取れるかは環境によって異なります。Copilotに読めた資料と要点・読めなかった資料を示してもらい、読めない部分は必要な本文やMarkdown／テキストで補います。

合意した計画はリポジトリ直下の`PLAN.md`へ保存し、実ファイルを開いて内容を確認してから実装へ進みます。作業・確認結果は実装時に`PROGRESS.md`へ残します。元資料を上書きして埋める手順はありません。
